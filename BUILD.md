# Сборка Nova Rust

Основной код — Rust + Tauri 2. UI находится в `ui/`, бизнес-логика — в `src/`. Зависимости закреплены `Cargo.lock`. На момент этой версии используется Rust 1.99+.

## Запуск из исходников

Установи Rust через rustup и платформенные зависимости Tauri.

```sh
cargo test --release --locked
cargo run --release --locked
```

`start.command` на Mac также умеет находить локальную среду разработки Nova. На Windows есть `start.cmd`.

Для Ubuntu 22.04/24.04:

```sh
sudo apt-get update
sudo apt-get install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev librsvg2-dev libayatana-appindicator3-dev patchelf
```

Для Windows нужны инструменты сборки Visual Studio C++ и WebView2. Для Mac — Xcode Command Line Tools.

## Проверки

```sh
cargo test --release --locked
./target/release/nova-rust --smoke
./target/release/nova-rust --probe-network
./target/release/nova-rust --test-game
```

На Windows исполняемый файл имеет расширение `.exe`.

- `--smoke` использует временный профиль: экраны, темы, контраст названий, синий акцент, Unbounded, анимации появления контента, проверка ника, отмена входа и восстановление после ошибки сохранения. Проверка отмены входа не вводит учётные данные Microsoft.
- `--probe-network` проверяет настоящий каталог Mojang и установку Fabric API, Complementary Reimagined и Fresh Animations.
- `--test-game` выполняет короткий запуск настоящего Vanilla 26.2 и закрывает его после инициализации. На локальном Mac переиспользуется неизменяемый кэш, если он есть.

Microsoft-вход с реальным аккаунтом, все исторические версии и сложные модпаки требуют отдельных проверок. Тест интерфейса не доказывает работоспособность каждого сочетания модов.

## Установщики

На Mac:

```sh
python3 scripts/package.py
```

Скрипт собирает `.app` со встроенным Rust-кодом и UI, подписывает его ad-hoc, проверяет подпись, создаёт DMG и проверяет образ. Java и Node.js в приложение не включаются. `--skip-build` упаковывает уже проверенный `target/release/nova-rust`.

На Windows и Linux:

```sh
cargo install tauri-cli --version '^2' --locked
cargo tauri build --bundles nsis
# Linux:
cargo tauri build --bundles appimage,deb
```

В GitHub Actions используется официальная Tauri CLI `2.12.4` из npm как инструмент сборки. Node.js нужен только агенту сборки; работающий лаунчер от него не зависит.

## GitHub Actions и Releases

Workflow: [rust-build.yml](.github/workflows/rust-build.yml).

1. Push в `main` запускает матрицу четырёх ОС/архитектур.
2. Каждый агент выполняет Rust-тесты, компиляцию и проверку интерфейса.
3. Mac проверяет подпись и запускает готовое `.app`; Windows создаёт NSIS `.exe`; Linux создаёт AppImage и DEB.
4. Установщики и UI-отчёты сохраняются как artifacts на 14 дней.
5. Тег `rust-v<версия из Cargo.toml и tauri.conf.json>` запускает публикацию. Несовпадение версий блокирует выпуск.
6. Публикуется сначала draft, затем загружаются все установщики и SHA256SUMS. После успешной загрузки выпуск становится публичной предварительной версией.

Пример следующего выпуска:

```sh
# Обнови Cargo.toml, Cargo.lock, tauri.conf.json и RELEASE_NOTES.md.
git add .
git commit -m "Release Nova Rust"
git tag rust-v3.0.0-beta.17
git push origin main rust-v3.0.0-beta.17
```

Не перезаписывай опубликованные теги. При исправлении версии создай новый номер.

Для распространения Mac-приложения без стандартных ограничений первого запуска понадобятся Developer ID и нотарификация. Скрипт ad-hoc подписи проверяет целостность, но не выдаёт приложению сертификат Apple.

## Архив Electron

Старый проект сохранён в `legacy/electron`, включая прежние инструкции и workflow как исторические файлы. GitHub запускает только workflow в корневой `.github/workflows`. Данные Electron, Java и Rust хранятся в разных папках.

Для проверки реального подбора Gemini используйте `--probe-ai` после настройки API-ключа в приложении. Проверка создаёт временный инстанс и не устанавливает моды.

Диагностика Horizon: `--horizon-sign-in` открывает вход по коду; `--prepare-horizon` проверяет аккаунт и готовит 26.3 с JDK 25; `--check-horizon-game` запускает подготовленный клиент на 180 кадров и сохраняет отчёт. Требуется собственный вход в Microsoft с Minecraft Java Edition.

## Проверки beta.15

`--probe-network` дополнительно проверяет описания и совместимые версии Modrinth, историю трёх установок и реальную установку базовой подборки оптимизации без Gemini.

Новые тесты загрузок поднимают временный HTTP-сервер на loopback: среда запуска должна разрешать локальный сокет. Они проверяют оборванный ответ, продолжение через Range, сервер без поддержки Range и несовпадение хеша. `--smoke` проверяет новые экраны и взаимодействия; ответы удалённых описаний и системного диалога импорта в UI-тесте подменяются, а чтение файлов Prism/MultiMC и сохранность оригиналов проверяются Rust-тестами.

## Проверки beta.16

Rust-тесты проверяют наследование параметров запуска и отсутствие токенов в профиле UI, чтение NBT, восстановление отдельного мира, сохранность оригинальных миров при переносе проверенного обновления, защиту от изменившейся исходной сборки, возврат рабочей точки и целостность резервного приложения.

`--smoke` дополнительно проверяет диалог профиля, командный поиск с клавиатуры, экран миров, рабочие точки и перенос тестовой копии через настоящий backend, фильтры консоли и очищенный отчёт, масштаб/контраст/уменьшение движения. Для карточек мира в UI используются тестовые ответы; работа с настоящими файлами и NBT проверяется модульными тестами.
