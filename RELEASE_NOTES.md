# Nova Rust 3.0.0-beta.17

- Все служебные кнопки, включая историю и Horizon, перенесены из нижней части боковой панели в верхнее меню «Ещё».
- В «Контенте» появился выбор сборки, включая автоматическое переключение фильтров версии и загрузчика.
- Выбранная сборка сохраняется между открытиями; выход из игры возвращает к запущенной сборке.
- Старый профиль без сохранённого выбора использует последнюю существующую сборку из истории.
- RageLand (mc.rageland.live) закреплён в серверах без замены личных записей и без повторного добавления существующего адреса.
- Перенос старых серверов объединяет их с закреплённым сервером.

# Nova Rust 3.0.0-beta.16

- Собственные параметры запуска каждой сборки с наследованием общих значений.
- Подтверждённые рабочие точки и обновление в отдельной копии с сохранением миров оригинала.
- Центр миров: превью, метаданные level.dat, размер, копирование и индивидуальное восстановление.
- Поиск ⌘K / Ctrl+K по сборкам, модам, серверам, настройкам и действиям.
- Поиск и уровни консоли, переход к связанным модам, очищенный диагностический отчёт с предпросмотром.
- Масштаб текста, высокий контраст, уменьшение движения и клавиатурная навигация вкладок.
- Сохранение приложения перед обновлением, ручное восстановление предыдущей версии и повторная проверка установщика.
- Проверка версий обновления больше не предлагает старую опубликованную beta поверх новой локальной.

Рабочее состояние подтверждает игрок после проверки в игре. Метаданные не гарантируют совместимость всех модов. Java-функции рабочих точек и центра миров не применяются к отдельному движку Horizon. Предыдущая версия приложения сохраняется локально; восстановление данных сборок выполняется отдельно.

# Nova Rust 3.0.0-beta.15 · локальная предварительная сборка

- Центр загрузок: прогресс, скорость, примерное время, пауза, отмена подготовки/установки, до трёх попыток. Проверяемые по хешу файлы продолжаются с диска при поддержке Range сервером.
- Готовность к игре: память, собственная Java, свободное место и локальные зависимости. Критические ошибки настроек блокируют запуск; для RAM и Java доступны исправления.
- История изменений контента через Nova с перечнем файлов и возвратом к точке сборки.
- Автокопии Java-миров перед изменением контента и раз в сутки перед игрой. Лимиты количества и объёма; ручные копии не удаляются, последняя автокопия сохраняется даже при превышении квоты.
- Перенос Prism/MultiMC и обычной папки Minecraft с предпросмотром. Для папки игры версия и загрузчик выбираются явно. Исходные данные сохраняются, аккаунты не копируются.
- Избранное Modrinth, описания проектов, совместимые версии и списки изменений.
- Базовый подбор оптимизационных модов без ключа Gemini, с проверкой стабильных версий и прежним откатом при ошибке установки.
- Предпросмотр обмена .mrpack с отчётом зависимостей и инструкцией внутри архива.
- Экономный интерфейс: статичный персонаж, без снега и анимаций. Переключатели доступны с клавиатуры.
- Резервирование базы настроек и восстановление предыдущего сохранения при повреждении.

Локально проверяется macOS ARM64. Проверки интерфейса используют тестовые ответы для удалённых описаний, импорта через диалог и подбора оптимизации; настоящая установка контента и запуск Minecraft проверяются отдельными командами. Полная совместимость произвольных модпаков не гарантируется. Windows, Linux и Mac Intel требуют сборки и проверки в CI.

Nova переходит на Rust + Tauri. Сохранены знакомый интерфейс, функции сборок и оформление с Unbounded и единым синим акцентом.

В этом выпуске:
- Готовые экраны «Минимализм», «Всё под рукой», «Персонаж в центре»; свои обои с затемнением и размытием.
- До восьми именованных экранов и перенос оформления через `.nova-theme.json`. Аккаунты, API-ключи и адреса серверов в файл не включаются.
- Настройки каждого модуля: масштаб текста, плотность фона и подробности; избранный сервер выбирается из собственного списка.
- Gemini учитывает установленные моды, желаемый FPS и, по отдельному переключателю, характеристики компьютера. Уже установленные проекты не предлагаются повторно.
- Восстановление Java-сборки после вылета: сравнение файлов с точкой сохранения, выбор временно отключаемых модов, резервная копия и возврат отключённых файлов из раздела «Моды».
- Новый редактор в духе экрана iPhone: мягкие карточки, удаление «−», угловые ручки размера, компактное управление сверху и «Готово» вместо нижней панели.
- Галерея из восьми модулей с поиском, предпросмотром и выбором размера. Выбор и расположение сохраняются.
- Контекстное меню по правой кнопке мыши в Nova отключено.
- Устранён сбой скачивания служебных файлов установщика при устаревших ответах CDN. Проверка контрольных сумм сохранена; файлы берутся с официальных GitHub-релизов Tauri.
- Шторка оформления: живой предпросмотр, темы, акцент, статичные фоны, скругления, компактность и блоки.
- Редактор расположения: перемещение и изменение размеров блоков на сетке, отмена, сброс и сохранение.
- Для Horizon на Intel Mac выбрана отдельная закреплённая сборка 26.3, поскольку v0.2.97 не содержит Intel-клиента.
- Исправлен вход Horizon: код Microsoft в Nova, общая авторизация для RUST-сборок, отдельные игровые папки и автоматический JDK 25 для подготовки ресурсов.
- Готовая ИИ-подборка автоматически раскрывается плавной прокруткой. Моды показаны с иконками Modrinth; при недоступной картинке остаётся аккуратная заглушка.
- ИИ-сборка с Gemini: описание → проверка предложений на Modrinth → выбор модов → установка с копией и откатом при ошибке. API-ключ добавляется в настройках и хранится только локально.
- Удобные подвкладки «Моды», «Модпаки», «Шейдеры», «Ресурспаки», «ИИ-сборка».
- Анимации появления новых сборок, загружаемого контента и подтверждения установки; аккуратное движение логотипа. Без анимированного фона и подсветки полей входа.
- Исправлены контраст названий во всех трёх темах, смена акцента между сборками, обработка первого входа и повторное сохранение после ошибки записи.
- Перенесены Minecraft, Modrinth, управление модами, резервные копии, серверы, Discord и Horizon.
- Исправлены откат пустого инстанса и ложные дубликаты вложенных библиотек Fabric; упаковка DMG повторяется при временной занятости системных ресурсов.
- Подготовлены отдельные установщики Mac ARM64, Mac Intel, Windows x64 и Linux x64. Релиз публикуется после проверок всех платформ.

Выбор файла в Assets:
- macOS-ARM64 … arm64.dmg — Mac с Apple Silicon.
- macOS-Intel … x64.dmg — Mac с Intel.
- Windows-x64 … setup.exe — Windows x64.
- Linux-x64 … AppImage или .deb — Linux x64.

На Mac закрой прежнюю Nova Rust перед заменой приложения. Установщики имеют контрольные суммы SHA-256. Mac-приложение подписано ad-hoc, но пока не нотарифицировано Apple.

Старые сборки можно скопировать через Настройки → Данные → Импортировать. Для Microsoft нужно войти заново. Старые данные и Electron-релизы сохраняются.

Для 26.3 RUST используется официальный Horizon, где нужен аккаунт с Minecraft Java Edition. Java-моды к этому движку не подходят.
