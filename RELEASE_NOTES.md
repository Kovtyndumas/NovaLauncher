Nova переходит на Rust + Tauri. Сохранены знакомый интерфейс, функции сборок и оформление с Unbounded и единым синим акцентом.

В этом выпуске:
- Устранён сбой скачивания служебных файлов установщика при устаревших ответах CDN. Проверка контрольных сумм сохранена; файлы берутся с официальных GitHub-релизов Tauri.
- Шторка оформления: живой предпросмотр, темы, акцент, статичные фоны, скругления, компактность и блоки.
- Редактор расположения: перемещение и изменение размеров блоков на сетке, отмена, сброс и сохранение.
- Для Horizon на Intel Mac выбрана отдельная закреплённая сборка 26.3, поскольку v0.2.97 не содержит Intel-клиента.
- Исправлен вход Horizon: код Microsoft в Nova, общая авторизация для RUST-сборок, отдельные игровые папки и автоматический JDK 25 для подготовки ресурсов.
- Готовая ИИ-подборка автоматически раскрывается плавной прокруткой. Моды показаны с иконками Modrinth; при недоступной картинке остаётся аккуратная заглушка.
- ИИ-сборка с Gemini: описание → проверка предложений на Modrinth → выбор модов → установка с копией и откатом при ошибке. API-ключ добавляется в настройках и хранится только локально.
- Удобные подвкладки «Моды», «Модпаки», «Шейдеры», «Ресурспаки», «ИИ-сборка».
- Анимации появления новых сборок, загружаемого контента и подтверждения установки; аккуратное движение логотипа. Без анимированного фона и подсветки полей входа.
- Исправлены контраст названий во всех трёх темах, смена акцента между сборками, обработка первого входа и повторное сохранение после ошибки записи.
- Перенесены Minecraft, Modrinth, управление модами, резервные копии, серверы, Discord и Horizon.
- Исправлены откат пустого инстанса и ложные дубликаты вложенных библиотек Fabric; упаковка DMG повторяется при временной занятости системных ресурсов.
- Подготовлены отдельные установщики Mac ARM64, Mac Intel, Windows x64 и Linux x64. Релиз публикуется после проверок всех платформ.

Выбор файла в Assets:
- macOS-ARM64 … arm64.dmg — Mac с Apple Silicon.
- macOS-Intel … x64.dmg — Mac с Intel.
- Windows-x64 … setup.exe — Windows x64.
- Linux-x64 … AppImage или .deb — Linux x64.

На Mac закрой прежнюю Nova Rust перед заменой приложения. Установщики имеют контрольные суммы SHA-256. Mac-приложение подписано ad-hoc, но пока не нотарифицировано Apple.

Старые сборки можно скопировать через Настройки → Данные → Импортировать. Для Microsoft нужно войти заново. Старые данные и Electron-релизы сохраняются.

Для 26.3 RUST используется официальный Horizon, где нужен аккаунт с Minecraft Java Edition. Java-моды к этому движку не подходят.
