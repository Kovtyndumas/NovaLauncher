# Улучшения Nova Launcher

Основа: `Kovtyndumas/NovaLauncher`, `main`, коммит `d5e46e12df94709cc103debf58659d577114a4b1`.

- Главная: избранные сборки находятся выше остальных; недавние игры запускаются нажатием. Кнопка «Продолжить» появляется для сборки с историей. Последняя выбранная сборка сохраняется между запусками.
- Поиск: ⌘K / Ctrl+K или «Поиск» в верхнем меню `⋯`. Стрелки выбирают результат, Enter запускает сборку или открывает раздел, Escape закрывает поиск. Доступны сборки, установленные моды выбранной сборки, серверы и разделы.
- Профили: меню `…` рядом с запуском → «Профиль запуска». Свои RAM, Java, JVM и окно; остальные значения наследуются из общих настроек. Версия и загрузчик задаются при создании инстанса; для другого сочетания создаётся отдельная сборка.
- Навигация: поиск, загрузки, история и Horizon находятся в верхнем меню `⋯`; боковая панель отведена сборкам и аккаунту.
- Загрузки: отдельный экран с прогрессом, скоростью, оставшимся временем, общей паузой и общим лимитом в КБ/с. Лимит `0` снимает ограничение. Одна скорость делится между параллельными загрузками.
- Восстановление: меню сборки или настройки → «Восстановить файлы». Используется та же подготовка файлов, что и при запуске Minecraft, но без входа в аккаунт и запуска игры. Контрольные суммы проверяются до замены файлов. Миры и пользовательские моды сохраняются.
- Оформление: существующие темы, акцент, компактный режим и редактор главного экрана сохранены. Избранный сервер и история включены по умолчанию для нового оформления; явный выбор скрытых модулей сохраняется.
- Без интернета: настройки → «Работать без интернета». Ранее установленные Java-сборки используют проверенные локальные файлы и сохранённый UUID игрока. Недостающий или повреждённый файл даёт объяснение; загружать его нужно с интернетом. Для первого запуска, онлайн-серверов и Horizon требуется сеть. Вместо сетевого скина показывается локальный знак Nova.
- Уведомления: сообщения внутри Nova о завершении загрузок и проблемах; две категории отключаются отдельно в настройках. Файлы одной загрузки группируются, последние сообщения видны в настройках текущего сеанса.
- Полосы прокрутки скрыты во всём интерфейсе, включая карточки, списки и диалоги. Прокрутка и редактор размеров блоков сохранены.

## Проверки

`cargo test --release --locked` проверяет бизнес-логику. Для теста скачивания нужен локальный loopback-сокет.

`cargo build --release --locked`, затем `target/release/nova-rust --smoke` проверяют приложение в отдельном временном профиле. Проверки UI включают поиск с клавиатуры, профили и наследование, настройки сети, ошибку восстановления без файлов, прогресс, паузу, уведомления, избранное и прокрутку. Отображение прогресса проверяется на тестовом ответе; реальные файлы и контрольные суммы проверяются Rust-тестами.

Реальный вход Microsoft, запуск игры с реальным аккаунтом и сетевой режим Horizon не проверяются автоматически этим набором.

## Управление сборками и интерфейс

В верхнем меню `⋯` доступны «Управление сборками», «Место на диске» и «Корзина сборок». В боковую панель новые служебные кнопки не добавляются. Главная сохраняет расположение виджетов; уточнены отступы, подписи, контраст второстепенного текста и состояния действий. Пробные сборки явно отмечаются на главной.

- Пробное обновление создаёт отдельную копию, включая тестовые миры. Обновляйте моды в этой копии через обычный раздел модов. Подтверждение доступно после успешного игрового сеанса с тем же содержимым. Затем можно просмотреть отличия и перенести только моды, конфигурацию, шейдеры и ресурспаки. Основные миры и профиль запуска сохраняются. Изменившаяся основная сборка блокирует перенос. Перед переносом создаётся резервная копия; журнал операции восстанавливает прежнее содержимое при прерывании приложения.
- Корзина хранит файлы и описание удалённой сборки. Восстановление возвращает её в библиотеку; при совпадении ID создаётся новый ID, существующая сборка не заменяется. Старые резервные папки без описания показываются отдельно и автоматически не восстанавливаются. Необратимое удаление корзины не добавлено.
- Место на диске показывает размеры сборок, миров, модов, резервных копий, общих ресурсов и корзины. Очистка требует предпросмотра и выбора временных файлов `.part` старше суток. Готовые файлы и игровые данные не включаются в очистку.
- Сравнение показывает добавленные, удалённые и изменённые файлы контента между двумя сборками, а также версии и загрузчики.
- Готовность к офлайну проверяет локальные файлы Java-сборки без сетевых запросов. Для Horizon действует собственный механизм подготовки.
- Сервер закрепляется отдельно за каждой сборкой в обзоре. Основная кнопка подключает к нему; одиночная игра остаётся в меню сборки.
- Скриншоты показываются по сборкам, по 12 на странице, с поиском по имени на текущей странице. Снимок можно открыть в системном приложении. Файлы больше 6 МБ открываются без встроенного предпросмотра.
- История фиксирует установки контента, обновления, включение и отключение модов, возврат файлов и перенос пробных обновлений. Изменения вне Nova отмечаются при следующем открытии раздела; постоянного слежения за папками нет.

Rust-тесты дополнительно проверяют сохранность миров при переносе, запрет переноса устаревшей копии, защиту от подтверждения непроверенных изменений, откат прерванной операции, восстановление из корзины с конфликтом ID, ограничения очистки, сравнение, историю, галерею и исключение символических ссылок при подсчёте размеров.

## Nova Studio, Liquid Glass и объёмный скин

Главная по умолчанию использует цельную панель запуска: название, действие и параметры сборки находятся вместе. Справа — сцена персонажа с именем игрока; сервер и история расположены ниже. Изменены типографика, размеры элементов, поля, вкладки и второстепенные действия. Сохранённые пользовательские сетки и редактор модулей продолжают использовать свои позиции. Для перехода со старой сетки выберите «Оформление → Готовые экраны → Nova Studio»: тема и акцент сохраняются.

Стеклянные панели доступны как отключаемый эффект для каждой из трёх тем. Предпросмотр, отмена и сохранение эффекта поддерживаются. Основа окна непрозрачная.

«3D Skin Layers» включены по умолчанию для превью персонажа; переключатель находится в настройках персонажа. Непрозрачные пиксели внешнего слоя превращаются в объёмные кубики. Внутренний слой не изменяется. Поддерживаются Default и Slim, геометрия следует суставам при движении. На часть тела создаётся одна объединённая геометрия — до шести дополнительных мешей, без отдельного вызова отрисовки для каждого пикселя. При смене сборки геометрия и материалы освобождаются. Высокое разрешение скина при построении объёмной формы приводится к сетке 64×64; исходная текстура остаётся у материала. При невозможности чтения пикселей сохраняется стандартный внешний слой.

Это функция 3D-превью Nova; игровой мод не устанавливается. Основа существующего просмотрщика: [skinview3d](https://github.com/bs-community/skinview3d/blob/master/src/model.ts).

## Сохранение и порядок

Крестик и Escape в оформлении сохраняют тему и цвет, как кнопка «Сохранить». Для отката предпросмотра есть отдельная кнопка «Отменить». При ошибке записи окно остаётся открытым и показывает причину.

Сборки можно перетаскивать в левой панели. Линия показывает место вставки; Alt + ↑ / ↓ перемещают сборку с клавиатуры. Явный порядок сохраняется и имеет приоритет над первоначальной сортировкой избранного. Выбор сборки записывается до загрузки списка модов; при запуске восстанавливается последняя существующая выбранная сборка.



## Installed content

Catalogue mod cards read the selected instance content index on every search. Installed and disabled mods show an installed label and cannot be installed again. Removed files clear the label. Unindexed JARs are identified by exact SHA-512 hashes through Modrinth when online. The install backend also checks existing projects before downloading.

The Glass status label has no background in either the standard screen or saved widget layouts. Glass controls use capsule shapes, thinner edges and pointer-following highlights; reduced motion and reduced transparency remain supported.

Текущий режим стекла: независимая настройка glassEffects для тёмной, графитовой и светлой тем. Нативная прозрачность окна не используется. Старый выбор темы glass переносится в light со включённым эффектом.
